🚀 سیستم پشتیبانی Helpdesk

RESTful API با قابلیت چت لایو لحظه‌ای

Django 5.2 DRF 3.15 JWT WebSocket Redis

🔐 احراز هویت با JWT

1️⃣ دریافت توکن:

POST /api/token/ 
{
    "username": "your_username",
    "password": "your_password"
}

2️⃣ ثبت‌نام کاربر جدید:

POST /api/users/register/ 
{
    "username": "customer1",
    "password": "123456",
    "email": "customer1@test.com",
    "role": "customer"  // customer, support, admin
}

3️⃣ استفاده از توکن در درخواست‌ها:

Authorization: Bearer YOUR_ACCESS_TOKEN_HERE

📡 لیست کامل Endpoints

👤 مدیریت کاربران

GET /api/users/ لیست کاربران (فقط ادمین)
GET /api/users/{id}/ جزئیات یک کاربر

🎫 مدیریت تیکت‌ها

GET /api/tickets/ لیست تیکت‌ها (با فیلتر status, priority)
POST /api/tickets/ ساخت تیکت جدید
GET /api/tickets/{id}/ مشاهده جزئیات تیکت
PUT /api/tickets/{id}/ ویرایش تیکت
DELETE /api/tickets/{id}/ حذف تیکت

💬 چت لایو (WebSocket)

WS ws://localhost:8000/ws/chat/{ticket_id}/ اتصال به چت لحظه‌ای تیکت

💡 تست سریع با cURL

# دریافت توکن
curl -X POST http://localhost:8000/api/token/ \
  -H "Content-Type: application/json" \
  -d '{"username":"admin","password":"admin123"}'

# دریافت لیست تیکت‌ها
curl -X GET http://localhost:8000/api/tickets/ \
  -H "Authorization: Bearer YOUR_TOKEN_HERE"

# ساخت تیکت جدید
curl -X POST http://localhost:8000/api/tickets/ \
  -H "Authorization: Bearer YOUR_TOKEN_HERE" \
  -H "Content-Type: application/json" \
  -d '{"title":"مشکل فنی","description":"خطا در ورود","priority":"high"}'

📱 اتصال WebSocket برای چت لایو

// JavaScript Example
const ws = new WebSocket('ws://localhost:8000/ws/chat/1/');

ws.onopen = () => {
    ws.send(JSON.stringify({message: 'سلام! مشکل دارم'}));
};

ws.onmessage = (event) => {
    const data = JSON.parse(event.data);
    console.log('پیام جدید:', data.message);
};
